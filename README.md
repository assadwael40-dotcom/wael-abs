# WAEL ADS

موقع عربي لإدارة خدمات الإعلانات والفيديوهات والطلبات، مع لوحة تحكم وقاعدة بيانات SQLite وتجهيز تكامل Paymob.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل على الكمبيوتر
1. فك ضغط المشروع.
2. افتح Terminal داخل مجلد `wael_ads`.
3. نفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
5. غيّر `SESSION_SECRET` و`ADMIN_PASSWORD` إلى قيم قوية خاصة بك.
6. شغّل:
   ```bash
   npm start
   ```
7. افتح `http://localhost:3000`.
8. لوحة الإدارة: `http://localhost:3000/admin.html`.

بيانات الدخول الافتراضية من `.env.example` هي `admin` وكلمة المرور `change-this-immediately`. غيّرها قبل تشغيل الموقع على الإنترنت.

## قاعدة البيانات
يتم إنشاء `data/wael-ads.sqlite` تلقائياً عند أول تشغيل. احتفظ بنسخة احتياطية من مجلد `data` بانتظام. لا ترفع هذا المجلد إلى GitHub.

## تفعيل Paymob
التكامل موجود في `src/paymob.js` وواجهات API في `server.js`. لا يعمل الدفع الفعلي حتى:
1. إنشاء حساب تاجر لدى Paymob واجتياز إجراءات التحقق وتفعيل وسائل الدفع المناسبة.
2. الحصول على API Key وIntegration ID وIframe ID وHMAC Secret من لوحة Paymob.
3. وضع القيم في متغيرات البيئة على الاستضافة، وليس داخل ملفات GitHub.
4. ضبط Webhook الخاص بالمعاملات على:
   `https://YOUR-DOMAIN/api/payments/paymob/webhook`
5. تنفيذ معاملات اختبارية والتأكد من HMAC وحالات النجاح والفشل والاسترداد مع إعدادات حسابك قبل استقبال أموال حقيقية.

مهم: لا تعتبر الطلب مدفوعاً لمجرد فتح صفحة الدفع. تحديث حالة `paid` لا يتم إلا من Webhook ناجح ومتحقق من HMAC. يجب مراجعة إعدادات HMAC وبيانات التكامل وفق وثائق Paymob الخاصة بحسابك قبل الإنتاج، لأن تفاصيل التكامل قد تختلف حسب نوع الحساب وواجهة Paymob المفعلة.

## رفع المشروع على GitHub
1. أنشئ Repository جديداً باسم `wael-ads`.
2. من داخل المجلد:
   ```bash
   git init
   git add .
   git commit -m "Initial WAEL ADS website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/wael-ads.git
   git push -u origin main
   ```
3. لا ترفع `.env` أو `data/` أو أي مفاتيح دفع.
4. GitHub يحفظ الكود؛ لا يشغّل Node.js backend أو قاعدة SQLite كاستضافة إنتاجية. انشر التطبيق على استضافة Node.js تدعم persistent disk، واضبط متغيرات البيئة هناك. اربط المستودع بالاستضافة للنشر التلقائي.

## قبل الإطلاق التجاري
- استبدل أمثلة الباقات والأسعار بما يناسب خدماتك.
- أضف روابط فيديوهاتك وصور أعمالك من لوحة التحكم.
- أضف سياسة خصوصية وشروط خدمة ووسيلة واضحة للتواصل.
- أضف حماية إضافية لتسجيل الإدارة (rate limiting، CSRF، ومراجعة أمنية) قبل استقبال بيانات العملاء على نطاق واسع.
- استخدم HTTPS دائماً.
